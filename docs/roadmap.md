# Roadmap

**This page is a pointer, not a snapshot** — it used to mirror status by hand and
invariably drifted (it last claimed v0.2.0 was current while three releases had
shipped). The living documents are authoritative:

- **Feature status, tiers, and plans:** [BACKLOG.md](https://github.com/LogicIncZo/zo-cobrowse/blob/dev/BACKLOG.md) — the feature roadmap
- **What changed per release:** [CHANGELOG.md](https://github.com/LogicIncZo/zo-cobrowse/blob/dev/CHANGELOG.md) (mirrored on this site's [Changelog](./changelog))
- **Release mechanics:** [CONTRIBUTING.md](https://github.com/LogicIncZo/zo-cobrowse/blob/dev/CONTRIBUTING.md) — git-flow (`dev` → `main`), deliberate `vX.Y.Z` tags

Short version: releases accumulate on `dev`; promoting `dev` → `main` and tagging
`vX.Y.Z` is the deliberate release step. Each release slate's design lives in
`docs/superpowers/specs/` (see `0.2.7-slate-design.md`).
