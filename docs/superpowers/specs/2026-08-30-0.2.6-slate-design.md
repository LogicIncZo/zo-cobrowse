# 0.2.6 Release Slate — Bug-Fix & Polish Round (design)

**Date:** 2026-08-30 · **Status:** approved in-session · **Milestone:** [0.2.6](https://github.com/LogicIncZo/zo-cobrowse/milestone/2)

## Goal

A deliberate pivot from the previously planned carry-over feature slate (#19 model picker, #10 cross-tab actions, #29 watch-tasks — **deferred**, revisit after this release). v0.2.5's real-world use surfaced a batch of observed bugs and UX friction; 0.2.6 is the release that closes them, plus four audit-first tracks that harden the project's measurement discipline (tests, perf, prompts, i18n).

All items were observed by the owner during daily use, diagnosed in-session 2026-08-30, and filed as issues **#62–#74** in the 0.2.6 milestone. Each issue carries its own evidence (file:line), fix direction, and verification criteria; this doc records the slate shape, build order, and the cross-cutting decisions.

## Cross-cutting rules

1. **Prompt changes** (#70, #71) stale the prompt-evals cache → `bun run evals:live` refresh rides the same PR; case ids stay stable (stream-replay fixtures route on them).
2. **Tests first where pure logic** (per repo pattern): `lib/` halves get schemas + unit tests before wiring (e.g. #69's cap lives in `lib/context-policy.js#decideTurn`).
3. **Every issue's verification section is the acceptance bar** — no item closes on "looks fixed."
4. Git-flow: one `fix/*`/`feat/*`/`chore/*` branch per issue, PR to `dev`; `main` promotion + tag `v0.2.6` is the deliberate release step.
