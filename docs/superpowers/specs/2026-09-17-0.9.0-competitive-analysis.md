## 1. What changed since 2026-08-29

1. **ChatGPT desktop kept shipping weekly; the access surface is the story.**
   - **GPT-6 Astra** (Aug 31–Sep 4 week): "advanced reasoning, computer use, and stronger judgment" — the computer-use model line continues to fold INTO the default assistant rather than a separate agent product.
   - **Pets Quick Chat** (Sep 7–11 week): a floating quick-chat surface with a **global hotkey** (Option+Space / Win+Alt+P), supporting **`@` context and `$` skills from the floating control** — sub-second access to the assistant without opening the main window.
   - **Windows Appshots** (same week): press both Alt keys → screenshot + text from the **frontmost app (any app, not just the browser)** lands in chat.
   - **GPT-5.5 retirement notice** (Sep 14–18 week, retires Oct 14) with in-product migration guidance — model-lifecycle comms are now an expected surface (our catalog ⚠ deprecated badges are the same muscle).
   - The Aug 24–28 browser wave is fully rolled: control in Edge/Brave/Opera/Vivaldi, **WebMCP Site tools** consumption (Work + Codex, GPT-5.6 Sol/Terra), cloud-browser sign-in, **event-triggered scheduled tasks** (Gmail/Slack/GitHub events instead of fixed schedules).
2. **Dia is in an integrations wave — "Your tool kit, in Dia."** v1.46.0 Linear (Aug 27), v1.47.1 **Notion** (Sep 3 — cross-tool search with results written into a Notion doc), v1.48.0 **Microsoft** (Sep 10 — Teams/SharePoint tools incl. a **proactive "morning brief" heads-up when a doc updates**). A further issue dated Sep 17 (v1.49-era, Microsoft-tools continuation) is landing this week — low confidence, the release-notes page still shows placeholder fields for it. The panel is being positioned as a **work OS**: SaaS integrations + proactive digests.
3. **Perplexity: Comet itself quiet** since the Jul 27 Computer-in-Comet-Assistant rollout; nothing new in Sept. The Aug 24 set stands: **Computer-in-Email** (email/forward a thread → agent session with your connectors, permissions, and Memory; replies only to the verified sender), **connector approvals "Always ask"** (pause before executing connector actions; recurring runs can inherit thread-level grants).
4. **Fellou's standing feature set confirmed** (homepage, no dated changelog): plan-first **Deep Action agent** with **real-time intervention — review/edit/approve/halt ANY step of the plan**; **Agentic Memory** (browser history + notes + personal knowledge base); **scheduled tasks** (one-time + recurring); **Shadow Window** — a back-end workspace where **multiple tasks run simultaneously**; open-source **Eko 2.0** agent framework; computer-use control of local desktop apps (permission-gated).
5. **BrowserOS: BrowserVLM** (Aug 17) — 0.54B-parameter **local GUI-grounding VLM** matching 7B-scale GUI models on ScreenSpot-Pro at 1/12 the size; grounding clicks in the UI on-device. Standing from March: **SOUL.md** plain-markdown local memory and **BYO-AI-subscriptions-as-agents** (ChatGPT Pro, Copilot, Qwen Code). No September posts.
6. **Parchi** (OSS, active — 360 commits / 545 stars): sidepanel copilot with **BYO provider profiles** (any OpenAI-compatible endpoint incl. Ollama/LM Studio), **orchestrator + subagent** architecture, **tool permissions + domain allowlist** safety controls, session history + export. The closest open-source structural peer to us.
7. **Chromium itself is absorbing the agent transport**: "Browser Actuator" flags (Chrome Story, Aug 20) — a remote-control transport that lets **Glic** (Chrome's Gemini surfaces) trigger/continue/stop automated browsing sessions. First-party agentic infra inside the browser is now visibly brewing; this is the strategic clock behind #49 (WebMCP) and, eventually, extension-platform risk.
8. **Anthropic**: Claude for Chrome remains alive but silent through the window; news is model-side (Fable 5.1 / Mythos 5.1, Sep 1). No new browser-extension capability.

## 3. New competitive axes

- **Instant-access surfaces**: floating quick-chat + global hotkey + capture-from-anywhere (ChatGPT Quick Chat / Appshots). The race is no longer just capability in the panel — it's **sub-second access** to the assistant from anywhere. We have panel keyboard shortcuts and the write-assist shadow-DOM widget machinery; nothing filed covers a general quick-ask surface.
- **SaaS tool-kit + proactive briefings** (Dia's wave): integration breadth as the panel's differentiator, plus the **morning-brief digest** shape (proactive, scheduled, cross-tool). Maps onto #29's engine + Zo's server-side integrations.
- **First-party Chromium agent infra** (Browser Actuator / Glic): the platform absorbing the transport layer extensions live on. Watch item, not an issue — but it puts a clock on #49 and on the extension's window as an independent surface.
- **Parallel background execution as a product surface** (Fellou Shadow Window, Comet Background Assistants): multiple simultaneous agent tasks is now a marketed feature, not an accident. Our run stores are multi-run **by construction** but nothing else is (see §4).
