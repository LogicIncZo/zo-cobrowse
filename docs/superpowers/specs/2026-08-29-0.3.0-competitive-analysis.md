# v0.3.0 Competitive Analysis — refresh of the sidepanel-AI field (late Aug 2026)

**Date**: 2026-08-29
**Status**: Approved as the 0.3.0 evidence base (issues #46–#54)
**Method**: web-research refresh pass against the 2026-08-20 baseline (`2026-08-20-0.2.0-competitive-analysis.md`); "changed since" findings verified against primary sources; absence of news confirmed explicitly.

## 1. What changed since 2026-08-20

1. **ChatGPT desktop is now a cross-browser agent layer** (Aug 25): browser control works in **Edge, Brave, Opera, Vivaldi** — not just Chrome; open tabs can be pulled into Work/Codex chats to act on signed-in sites. Plus **WebMCP "Site tools"** consumption (GPT-5.6 Sol/Terra), cloud-browser sign-in prompts, and **scheduled tasks triggering on app events** (Gmail/Slack/GitHub) instead of fixed polling. Aug 10–14: **Computer History** — app/site activity becomes a searchable timeline feeding **memories** (admin/consent-gated; EU/CH/UK Aug 20). This is a first-party competitor to companion extensions on their own turf.
2. **Opera Neon pivoted to "browser as agent runtime"** (Aug 2026): third-party agents use it **free via MCP or CLI** (browsing without an account; agent connection needs one). Builds on the March MCP Connector. Cloud-executed Do/Make agents unchanged, $19.90/mo. **No undo/revert found** (confirmed absent).
3. **WebMCP: trial → first major consumer.** Origin trial live in **Chrome 149** (Android first; desktop last ~Chrome 156, ship target 157). ChatGPT's Aug-25 consumption means site-declared tools now have a working agent client outside Chrome's Gemini.
4. **Perplexity supervision tightened**: **"Connector approvals — Always ask"** (Aug 24) pauses agent actions before execution — the newest explicit per-connector permission surface. Computer in Email; GPT-5.6 Terra/Luna defaults. **Comet itself unchanged**: free tier, Background Assistants + Scheduled Tasks, Max $200/mo.
5. **Dia: weekly cadence resumed; memory hardened.** v1.43.1 Swipeable Profiles (Aug 6), v1.44.0 LinkedIn (Aug 13), v1.45.0 Notes (Aug 20), Linear (Aug 27). Memory now gains more browsing context but **excludes sensitive sites (banks) and incognito tabs** — privacy exclusion is part of the converged memory UX. Windows beta actively testing.
6. **Gemini in Chrome**: "auto browse" (agentic multi-step: forms, expense reports, shopping) in **US preview for AI Pro/Ultra**; supports UCP; "designed to pause and explicitly ask for your confirmation" on purchases/social posts; Google Password Manager only with permission. **Personal Intelligence** (past-conversation memory) "coming months" — not shipped. "Select from screen" unchanged (shipped Jun 24).
7. **BrowserOS**: **BrowserVLM** announced Aug 17 — a 0.54B-parameter **local GUI-grounding VLM** for on-device element targeting; releases Aug 20–21. "neo" agents-only second browser continues.
8. **Sider v5.32.2 (Aug 24)**: **Browser Agent** (acts in the live browser, pause anytime) + **Sider Code** — per-website plain-word customizations **remembered across visits** (site-level persistent memory).
9. **Agent payments**: Revolut Pay (Aug 2026) among first EU AP2-compatible methods (UK/EEA); Chrome auto browse backs **UCP** (Shopify/Etsy/Wayfair/Target); OpenAI Instant Checkout reportedly shut March 2026; **ACP continues**. Confirmation UX converged on pause + explicit confirm for purchases.

## 2. Confirmed unchanged

- **Fellou**: no August news; scheduled tasks + Shadow Window pattern stand.
- **Copilot Vision**: no new in-browser vision capability in the window.
- **HARPA**: v7.0 workflow engine (loops/conditions/jumps) stands; workflow-automation direction, not live co-browsing.
- **Parchi**: per-tool/domain toggles as before; nothing new.
- **Max AI**: routine cadence.
- **Voice**: nothing new; standing pattern is transcript-into-composer (Comet sidebar voice commands; Gemini side-panel dictation Jan 2026; Gemini 3.5 Transcribe dictation into Chrome fields in flight). **We already ship both STT (mic button) and TTS output (chrome.tts — live-verified 2026-08-29, `e2e/probe-tts.ts`)**; the voice gap is essentially closed for the transcript-into-composer pattern everyone actually uses.
- **Cross-session memory**: no converged standard; the emerging shape is *activity timeline + memories + privacy exclusions + opt-in/admin gates* (ChatGPT Computer History, Dia's exclusions, Gemini pending). One comparison still calls robust memory "unsolved across providers" — an opening for a workspace-file-based design.

## 3. New competitive axes

- **ChatGPT desktop as agent layer** in any Chromium browser using existing sign-ins.
- **Browser-as-MCP-runtime**: Opera Neon free for agents via MCP/CLI; BrowserOS neo hosting coding agents. Agents consuming browsers, not chat panels.
- **Local GUI-grounding models** (BrowserVLM): on-device element detection as differentiator vs DOM-capture extensions.

## 4. Verdict — the 0.3.0 slate

Theme: **"Memory, Audit & Control"** — close the retention gap (memory), ship the trust surface the market just converged on (permissions, undo) as differentiators, and bank the small wins.
