Zo Co-browse

Configure your co-browsing connection to Zo Computer

🔌 Connection

🎨 Theme

🧠 Persona

Pin the Zo persona that runs your requests. The Mode you pick in the side panel decides how Zo behaves; this sets which persona executes it.

Leave as Zo to use the default, or pick a persona you've created.

🧠 Model

✎ Prompts

Tune what each Mode sends to Zo — system prompt, instructions, and how much page context. Built-in Modes keep an editable override (Reset restores the original); custom Modes are edited directly. Page context still requires !context per turn in the chat.

📷 Screenshot & Vision

      

        
        

          Zo will see the page visually — layout, images, colors, and UI state — for more accurate context understanding.
          Screenshots are sent only to your configured Zo endpoint and never stored.
        

      

    


    
    

      
✍️ Write Assist

      

        
        

          When a text area is focused, a small Zo icon appears at its corner. Click it to have Zo expand or polish
          your draft — you preview the result before it is filled in. Nothing is written without your approval.
        

      

    


    
    

      
🛠️ Debug & Diagnostics

      

        
        

          Records timing metadata (message hops, capture and stream durations) in a capped in-memory
          ring while the browser runs. Metadata only — never page text, prompts, or tokens. Nothing
          leaves the browser unless you export it below.

⌨️ Keyboard Shortcuts

      
Use the table below to view available shortcuts. To remap them, visit chrome://extensions/shortcuts.

      

        
          

            Shortcut
            Action
          

        
        
          

            Ctrl+Shift+Z / Cmd+Shift+Z
            Open the Zo Co-browse side panel
          

          

            Ctrl+Shift+S / Cmd+Shift+S
            Summarize the current page with Zo
          

          

            Ctrl+Shift+N / Cmd+Shift+N
            Start a new Zo chat
          

          

            Ctrl+Shift+E / Cmd+Shift+E
            Extract structured data from this page
